## 1. Общая концепция

B2B-каталог производственной компании, три типа спроса — три раздела:

| Раздел | Тип спроса | Модель |
|-|-|-|
| **Производство** | «изготовьте под мой проект» | каталог возможностей, заявка с чертежом/размерами |
| **Услуги** | «выполните операцию» | 8 сервисов, отдельно или в комплексе |
| **Готовые решения** | «продайте готовое» | типовые модели с фиксированной ценой и сроком |

Целевая аудитория: строительные организации, промышленные предприятия, управляющие
компании, муниципальные заказчики, девелоперы.

**Единая терминология:** раздел называется «Готовые решения» ВЕЗДЕ (на главной
карточка «Готовые продукты» переименовывается).

## 2. Типы страниц (трёхуровневая модель)

| Код | Тип | Что это | Шаблон |
|-|-|-|-|
| **[НАПР]** | Направление | Страница направления производства со списком подкатегорий (например «Металлоконструкции») | категория: hero, сетка карточек-подкатегорий, SEO-текст, CTA |
| **[КАТ]** | Категория / подкатегория | Страница семейства изделий (например «Козырьки на стальном каркасе»): обзор, типы изделий якорными блоками, галерея, цены «от», CTA | категория с якорными блоками |
| **[ПОС]** | Посадочная | Отдельная страница под тип изделия с собственным кластером запросов (например «Козырьки входных групп») | облегчённая карточка: описание, фото, ТХ, цена «от», FAQ, CTA |
| **[КАРТ]** | Карточка изделия | Заказываемая единица: галерея, паспорт изделия, опции, доставка (эталон — «Лестница 1.460») | продуктовый шаблон |
| **[БЛОК]** | Якорный блок | НЕ отдельная страница: секция с якорем на странице [КАТ]. Кандидат на выделение в [ПОС] | — |

**Правило создания [ПОС] («страница должна заслужить существование») — все 3 условия:**
1. отдельный кластер поисковых запросов с реальным спросом;
2. отдельный покупательский сценарий;
3. есть уникальный контент: свои фото, свои ТХ/цены, свои кейсы (не клон соседней страницы).

Не прошло хотя бы одно условие → [БЛОК] на родительской [КАТ]. Блок выделяется в
страницу позже без ломки структуры (блок превращается в ссылку).

**Готовые решения — обратная логика:** максимальная детализация, карточка модели
с ценой обязательна.

## 8. Контентные правила

1. Тексты можно генерировать ИИ, но каждый факт — из реальности производства:
   материалы, сроки, ограничения, реальные фото (не выдумывать и не скачивать).
2. Обязательная вычитка технологом/ПТО перед публикацией.
3. Цены: фиксированные — для Готовых решений; вилки «от … BYN» — для заказных.
   «Цена по запросу» допустима только там, где вилку дать невозможно.
4. Никаких страниц-клонов: если для страницы нет ≥3 уникальных элементов
   (фото, ТХ/цены, кейсы/FAQ) — она остаётся якорным блоком.
5. Запрещено выдумывать статистику, награды, несуществующие сертификаты.

## 9. Продающие блоки (внедряются по мере создания страниц)

1. Цены «от» на всех страницах категорий.
2. Кейсы: Портфолио переупаковывается в мини-кейсы (объект, заказчик, тоннаж,
   срок, фото) с фильтром по категориям.
3. CTA по типу спроса: Производство — «Отправьте чертёж — КП за 1 день» (поле
   файла); Готовые решения — «Скачать каталог PDF» + «Заказать».
4. Блок «Как мы работаем» (заявка → расчёт 1 день → договор → производство →
   доставка/монтаж) на страницах категорий.
5. Страница «Производственные мощности» (цех, станки, видео).
6. Блок сертификатов и телефонов отделов — уже в шаблоне.

## 10. План работ (этапы)

Принцип: каждая затронутая страница пересобирается в новом фирменном стиле.
После каждого этапа — показ заказчику, правки, коммит, только затем следующий этап.

**Этап 0 — Фундамент (быстрые правки)**
- Переименовать «Готовые продукты» → «Готовые решения» на главной.
- Обновить выпадающее меню «Производство» под новую структуру подкатегорий (по мере готовности страниц).
- Переименовать «Лестницы металлические по серии» → «Лестницы металлические».
- Спроектировать и утвердить шаблон страницы-категории [КАТ] в новом стиле (одна пилотная страница).

**Этап 1 — Готовые решения (максимальный эффект на конверсию)**
- Хаб «Готовые решения» в новом стиле.
- «Остановочные павильоны»: страница-каталог + карточки моделей с ценами (контент готов ✅).
- Далее по готовности контента: Торговые павильоны → Велопарковки → ТБО → Кабины → Навесы ТБО → Козырьки → МАФ. КПП и Бытовки — последними.

**Этап 2 — Пилот заказных изделий**
- «Козырьки на стальном каркасе» [КАТ] + посадочная «Козырьки входных групп» [ПОС].
- Тексты по правилам п. 8, согласование с заказчиком → утверждение подхода для тиражирования.
